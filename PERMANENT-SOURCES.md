# Keep one OBS source per game

Faith only needs one source for Vault, one for Presents, one for Darts, and one
for Piñata. Different saved versions, renamed buttons, amounts, ranges and
styles within a game all share its permanent display link.

## One-time update for an existing source

1. Between viewers, close older control tabs and reopen the updated game controls
   in the browser where Faith saved her settings.
2. Copy the **Permanent display link** (under **Permanent stream display**).
3. In OBS, open **Properties** for that game's existing Browser Source and paste
   the link into **URL** if it differs. Keep the existing placement and size.
   **Do not create another source.** Refresh the source to load the update.
4. Leave one control tab open per game type.

The original saved version's link is adopted automatically. If OBS already uses
that link, only a refresh is needed. Links from older copied versions still work
while that version is selected, but use the permanent link to switch freely.

## Every game after that

- Edit settings and **Save changes** to update the existing saved version.
- Use the four game/range buttons for different prize ranges.
- Use **Saved version** at the top of the private controls for a different saved
  setup or style. Its **Edit this version** link opens the matching settings.
- The OBS source follows that selection without a new URL, reconnect or source.
- Finish the current viewer before switching versions. Switching never starts
  a round by itself. Names, ranges and selector controls stay off the overlay.

Darts uses 540 × 540. Vault, Presents and Piñata use 420 × 460. All remain
transparent. Existing game art, audio, odds and prize rules are unchanged.

Settings and permanent links remain local to the browser/profile. Clearing
browser data or moving to another browser/computer does not transfer its link.
Download a settings backup before moving; keep complete display links private.
