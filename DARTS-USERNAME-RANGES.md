# Darts username ranges

In a saved Darts game’s editor or control page, find **Username ranges**.
Enter a username, a minimum final total and a maximum final total, then select
**Save range**. For example, `faithfan`, `400`, `600`.

On the control page, enter that username in **Viewer name**, then throw as usual.
The match notice confirms the range before the first throw. Capitals and a leading
`@` do not matter; similar names do not match. This matches the name Faith types,
not an authenticated Twitch account.

Each new matching round prepares its cash values and complete target sequence
before the first throw. The final total is inside the saved range **after** gold
and multipliers. Extra darts, bonus amounts, dart limits and the bonus within the
first three throws still follow the game’s settings. Every award comes from the
value shown on the hit balloon, including its current gold boost. Classic boards
also support ranges with prepared band values.

These rounds replace ordinary cash amounts and random prize draws. The default
amounts and odds still apply to viewers without a matching range. A multiplier-only
game may not support an exact, very narrow range (for example exactly $1 with a
required ×3); the game reports this before starting. Widen the range or enable
another bonus if that happens. Totals and individual values can include cents.

Ranges recur until edited or removed. Edits affect future rounds; refreshes,
changes to settings and removal of a rule do not change an active prepared round.
Settings backups and duplicated games include ranges. Rules belong to each saved
game and stay in this browser; they are not sent to the transparent display. The
display receives the visible board and current hits, never the username table or
future target sequence.

## Try it before streaming

Select **Demo** beside any saved username to play a complete automatic round.
Every dart and extra dart plays in order with a short pause to read each prize,
followed by the total and celebration. **Stop demo** lets the current dart finish
without starting another; **Reset demo** clears the sample. Select Demo again
for a fresh round. From live controls, Demo opens a separate editor tab and keeps
the live control connection running.

You can also enter a saved name in the editor’s **Demo viewer** field. The match notice
shows the range. Use **Throw demo dart** once per dart to play through, or use
**Preview finale** for a disposable completed sample. Resetting or changing the
name starts a fresh demo. Demos never start a live round. Clear the demo username
to use the separate forced-bonus buttons.

The stream display remains a transparent 540 × 540 square. Existing display links
continue to work. Refresh the controls and the Browser Source after updating.
