# Piñata v13 — smoother side changes and username ranges

The bat keeps its impact and follow-through, then travels behind the crown to
the opposite side. It holds there until Faith clicks again. The next wind-up
starts at that exact pose. Both directions keep the original 480ms impact and
1500ms swing length. No sprite resizing, new backdrop, or overlay expansion.
The final hit still uses the existing royal finale, with no transfer to an
unused next side. Reduced motion hides the bat as before.

In **Faith’s controls → Username ranges · private**, save a username, minimum
and maximum final total. Enter that name in **Playing for** to use its rule.
The range covers the entire game, including all extra swings and multipliers.
It applies every time until edited or removed; names ignore case, surrounding
spaces and a leading @. Matching is based on the name Faith enters, not Twitch
account verification or chat automation. Up to 100 rules per saved game.

Rules stay in this browser for this saved game. Ordinary editor saves preserve
them; saving a separate game starts a separate list. An active game freezes its
rule and prizes, so editing/removing a rule affects future games only. The main
editor’s demo recognizes saved usernames and provides **Watch username sample**
without changing the rule or a live round.

The whole-dollar target is selected within the inclusive saved range. Planned
cash and eligible bonuses add up exactly using the normal award engine. First
hit remains cash; configured starting swings and round limit still apply.
Cash amounts are customized; ordinary reward odds do not apply to these games.
Disabled bonuses stay disabled. A bounded cash-only fallback handles narrow
ranges or extreme settings. No clamp, subtraction or replacement at the end.

The display packet excludes the username table, saved range and future prize
plan. Only Faith’s controls receive that metadata. Local schema 2 preserves
older settings, display links and active ordinary rounds while stopping older
open controllers from running a planned game with the old random engine.
**Refresh Faith’s controls, editor and OBS Browser Source after this update.**

Verification includes 2,400 complete range games, edge RNG and custom swing
limits, repeated usernames, concurrent clicks, reload/resume, frozen rules,
actual publisher privacy, continuous bat poses and compact-stage bounds.
Browser checks cover both transfer directions, pause before the next click,
range save/edit/reload, a full practice game, and the paired transparent display.
Audio scores, artwork and the existing volume mix are unchanged.
